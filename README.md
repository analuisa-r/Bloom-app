# Bloom 🌱

Aplicação web para acompanhamento de hábitos, metas pessoais e bem-estar emocional, 
com foco em ajudar a manter uma rotina de autocuidado de forma simples e acolhedora.

## Problema
Manter hábitos saudáveis, metas pessoais e momentos de reflexão organizados costuma 
exigir o uso de vários aplicativos diferentes, o que dificulta a criação de uma rotina 
consistente de autocuidado.

## Público-alvo
Pessoas que queiram organizar hábitos, metas e bem-estar emocional em um só lugar, 
com foco especial em mulheres que lidam com múltiplas responsabilidades no dia a dia.

## Funcionalidades principais (planejadas)
- Controle de hábitos com sequência (streak) de dias
- Checklist diária
- Metas pessoais
- Diário pessoal
- Frase motivacional do dia
