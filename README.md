# Bloom 🌸
*Floresça um dia de cada vez.*

Aplicação web para acompanhamento de hábitos, metas pessoais e bem-estar emocional, com foco em ajudar a manter uma rotina de autocuidado de forma simples e acolhedora.

🔗 **Site publicado:** https://analuisa-r.github.io/Bloom-app/

## Problema
Manter hábitos saudáveis, metas pessoais e momentos de reflexão organizados costuma exigir o uso de vários aplicativos diferentes, o que dificulta a criação de uma rotina consistente de autocuidado.

## Público-alvo
Pessoas que querem organizar hábitos, metas e bem-estar emocional em um só lugar, com foco especial em mulheres que lidam com múltiplas responsabilidades no dia a dia.

## Funcionalidades

### Já implementadas
- Landing page
- Saudação personalizada com o nome da usuária
- Cadastro, edição e exclusão de hábitos
- Checklist de hábitos do dia, com barra de progresso

### Planejadas
- Sequência (streak) de dias consecutivos de cada hábito
- Metas pessoais
- Diário
- Frase motivacional do dia
- Resumo semanal de progresso

## Tecnologias
- HTML, CSS e JavaScript (sem frameworks)
- Armazenamento local no navegador (localStorage)
- GitHub Pages para publicação
