# Documento de Requisitos — Bloom (versão inicial)

## Requisitos Funcionais
- RF01: O sistema deve permitir que a usuária crie uma conta e faça login.
- RF02: O sistema deve permitir criar um hábito com nome, frequência e ícone/cor.
- RF03: O sistema deve permitir marcar um hábito como concluído no dia atual.
- RF04: O sistema deve calcular e exibir a sequência (streak) de dias consecutivos de um hábito.
- RF05: O sistema deve exibir uma checklist com os hábitos do dia atual.
- RF06: O sistema deve permitir criar uma meta pessoal com título, descrição e data-alvo.
- RF07: O sistema deve permitir vincular um hábito a uma meta.
- RF08: O sistema deve permitir marcar uma meta como concluída.
- RF09: O sistema deve permitir criar, editar e excluir entradas de diário.
- RF10: O sistema deve exibir uma frase motivacional diferente a cada dia.
- RF11: O sistema deve exibir um resumo visual do progresso de hábitos.

## Requisitos Não Funcionais
- RNF01: O sistema deve ser responsivo (celular e computador).
- RNF02: As telas principais devem carregar em menos de 2 segundos.
- RNF03: Os dados devem ser armazenados de forma persistente em banco de dados.
- RNF04: A interface deve seguir uma paleta de cores consistente e acolhedora.

## Observação
Este documento representa a primeira versão dos requisitos, levantada no início do 
projeto. Será atualizado ao longo do semestre conforme o desenvolvimento avançar.
